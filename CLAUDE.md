# MyWebApp

Монорепозиторий: клиент на Vue, API-шлюз и бэкенд-сервисы на ASP.NET Core.

## Структура репозитория

- `Frontend/ClientApp` — исходный код клиентского приложения.
- `Frontend/Release` — собранный билд клиента для деплоя.
- `Backend/Gateway` — API-шлюз, единая точка входа в систему.
- `Backend/BuildingBlocks` — общий код, переиспользуемый всеми бэкенд-сервисами (например, обработка исключений).
- `.github/workflows` — CI/CD.

Бэкенд-сервисов будет несколько. Каждый — отдельное `.NET`-решение (`.slnx`), собранное по единому архитектурному шаблону. Общего решения на весь репозиторий нет.

## Правила ведения документации

- `CLAUDE.md` — оглавление. Детали — в `Docs/*.md`.
- Описывается идейная структура: что как лежит и как организовано. Не конкретные файлы.
- Стиль: структурированно, технически, человекопонятным языком.
- Предложения короткие и простые. Без сложных конструкций и странных оборотов речи.
- Без повторов. Каждая мысль — в одном месте.
- Не смешивать разные логические секции внутри одного раздела.
- Текст обезличенный, без обращения к читателю и без ссылок на конкретных людей.
- Диалоги и ход обсуждения в документацию не попадают. Только то, что явно попросили зафиксировать.
