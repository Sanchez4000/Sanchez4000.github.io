# MyWebApp

Монорепозиторий веб-приложения. Клиент — SPA на Vue 3 и TypeScript. Серверная часть — API-шлюз и бэкенд-сервисы на ASP.NET Core (.NET 10).

## Структура репозитория

| Путь | Содержимое |
| --- | --- |
| `Frontend/ClientApp` | Исходный код клиентского приложения |
| `Frontend/Release/dist` | Готовый билд клиента, который публикуется |
| `Backend/Gateway` | API-шлюз: единая точка входа для клиента |
| `Backend/BuildingBlocks` | Сквозной код, общий для бэкенд-сервисов |
| `Backend/PingService` | Сервис проверки доступности и образец для новых сервисов |
| `.github/workflows` | Рабочие процессы GitHub Actions |

Шлюз и каждый бэкенд-сервис — отдельное решение `.slnx` со своим набором зависимостей.

## Правила ведения документации

Структура:

- `CLAUDE.md` — оглавление и точка входа. Содержательные детали — в `Docs/*.md`.
- Один документ — одна тема.
- Каждый факт описан в одном месте. Остальные документы ссылаются на него.

Содержание:

- Документируется устройство системы: из чего она состоит и как части связаны. Не перечень файлов.
- Описывается только текущее состояние. Без планов, истории и хода обсуждений.
- Фиксируется то, что попросили зафиксировать.

Язык:

- Одно предложение — одна мысль.
- Термины единообразны во всей документации.
- Текст обезличенный: без обращения к читателю и упоминания людей.
