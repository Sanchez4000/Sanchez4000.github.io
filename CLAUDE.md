# MyWebApp

Монорепозиторий: клиент на Vue, API-шлюз и бэкенд-сервисы на ASP.NET Core.

## Структура репозитория

- `Frontend/ClientApp` — исходный код клиентского приложения.
- `Frontend/Release` — собранный билд клиента для деплоя.
- `Backend/Gateway` — API-шлюз, единая точка входа в систему.
- `.github/workflows` — CI/CD.

Бэкенд-сервисов будет несколько. Каждый — отдельное `.NET`-решение (`.slnx`), собранное по единому архитектурному шаблону. Общего решения на весь репозиторий нет.
