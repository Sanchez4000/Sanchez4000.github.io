# Деплой и CI/CD

## Что деплоится

Автоматически деплоится только клиентское приложение — как статический сайт на GitHub Pages.

Бэкенд-сервисы (шлюз и API) в CI/CD не участвуют. Их деплой пока не автоматизирован.

## Как это работает

Собранный билд клиента хранится прямо в репозитории, как обычные файлы. Сборка клиента выполняется вручную, локально, и её результат коммитится.

GitHub Actions ничего не собирает. При пуше в ветку `develop` он берёт уже готовые файлы билда и публикует их на GitHub Pages.

## Важно

Если изменить исходный код клиента и не пересобрать билд вручную, деплой опубликует старую версию.
