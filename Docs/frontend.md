# Клиентское приложение

## Технологии

Vue 3, TypeScript, Vue Router, Vuex.

## Структура

- **views** — страницы приложения, привязанные к маршрутам.
- **components** — переиспользуемые UI-компоненты.
- **router** — описание маршрутов и переходов между страницами.
- **store** — глобальное состояние приложения (Vuex).

Маршрутизация работает в hash-режиме (`#/path`). Это упрощает деплой на статический хостинг: серверу не нужна отдельная настройка под клиентский роутинг.

## Состояние на сегодня

Приложение — стартовый каркас. Нет UI-библиотеки компонентов, нет HTTP-клиента, нет обращений к API, нет тестов. Store не содержит состояния, модулей и экшенов.
