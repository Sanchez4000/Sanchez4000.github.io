# Клиентское приложение

SPA, работающее в браузере. Исходный код — в `Frontend/ClientApp`.

## Технологии

| Назначение | Технология |
| --- | --- |
| Каркас приложения | Vue 3 |
| Язык | TypeScript в строгом режиме |
| Маршрутизация | Vue Router |
| Глобальное состояние | Vuex |
| Сборка | Vue CLI на webpack |
| Стили | SCSS |
| Проверка стиля кода | ESLint и Prettier |

## Структура исходного кода

| Каталог | Содержимое |
| --- | --- |
| `src/views` | Страницы, привязанные к маршрутам |
| `src/components` | Переиспользуемые UI-компоненты |
| `src/router` | Описание маршрутов |
| `src/store` | Хранилище Vuex |
| `src/assets` | Ресурсы, проходящие через сборку |
| `public` | HTML-шаблон и файлы, попадающие в билд без обработки |

В путях импорта префикс `@` указывает на `src`.

## Маршрутизация

Маршруты работают в hash-режиме: адрес страницы выглядит как `/#/about`. Для сервера такой адрес — одна и та же страница, поэтому статическому хостингу не нужна отдельная настройка перенаправлений.

Страницы подключаются двумя способами. Стартовая входит в основной бандл. Остальные импортируются лениво и попадают в отдельные файлы, которые загружаются при первом переходе.

## Сборка

| Команда | Действие |
| --- | --- |
| `npm install` | Установка зависимостей |
| `npm run serve` | Локальный запуск с горячей перезагрузкой |
| `npm run build` | Сборка билда в `ClientApp/dist` |
| `npm run lint` | Проверка и автоисправление стиля кода |

Каталог `ClientApp/dist` в репозиторий не попадает. Как билд доходит до публикации, описано в [Деплой](deployment.md).
